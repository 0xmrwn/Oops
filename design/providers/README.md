# Provider identity

ChatGPT marks (`ChatGPTMarkWhite`, `ChatGPTMarkBlack`) are unmodified `chatgpt-button-white-21.svg` / `chatgpt-button-black-21.svg`, OpenAI's brand files for the sign-in button, as published in the `assets/brand/` folder of OpenAI's Sign in with ChatGPT devkit (commit 0a36fef, retrieved 23 October 2026). They are OpenAI brand assets, not code: Oops uses them under the [OpenAI brand guidelines](https://openai.com/brand/), as the [UI/UX guidelines](https://developers.openai.com/siwc/ui-ux-guidelines) ask (approved OpenAI branding and assets), and only on the official Continue with ChatGPT button and the ChatGPT card. The ChatGPT name and marks belong to OpenAI; they identify the integration, not Oops branding or an endorsement, and are not covered by Oops's MIT licence. No devkit code is used. Compiled by actool with vector preservation. Compatible API uses the native SF Symbol network to represent a configurable endpoint, without implying a particular provider.

Every other mark, including ChatGPT's mark in provider lists and headers (`OpenAIMark`, `openai.svg`, so it matches the others' size), is a monochrome template from [`@lobehub/icons-static-svg` 1.98.0](https://www.npmjs.com/package/@lobehub/icons-static-svg) (retrieved 24 October 2026): `ClaudeMark` (`claude.svg`), and the API presets `CerebrasMark`, `DeepSeekMark`, `FireworksMark`, `GeminiMark`, `GroqMark`, `LMStudioMark`, `MistralMark`, `OllamaMark`, `OpenRouterMark`, `TogetherMark` and `XAIMark` (`xai.svg`). Only the `1em` size, inline style and title were removed, `currentColor` became black for template rendering, and packed SVG arc flags were spaced out for CoreSVG. They identify the providers Oops connects to; the names and marks belong to their owners. An API without a preset uses the SF Symbol `server.rack`.
