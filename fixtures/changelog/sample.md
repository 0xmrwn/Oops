# Changelog

Sample with several releases, for `-SettingsPreviewChangelog fixtures/changelog/sample.md`. The top one matches the installed 0.1.0, so with `-SettingsPreviewUpdate available` the pending 0.2.0 sits above it.

## 0.1.0

- Try fixes right inside Settings.
- Record your own shortcuts for **Fix text** and **Restore original**.
- See your stats: fixes by day, mistakes per fix and the fastest model.

## 0.0.3

- Sounds when a fix starts, lands or fails.
- Edit the correction rules under General → Customize.

## 0.0.2

- Gemini, Groq and Mistral presets for API providers.
- The capsule follows a composer that grows while it fixes.

## 0.0.1

- Fix the draft you're typing in any app with **Hyper-W**, and restore the original with **Hyper-R**.
- Fix with ChatGPT, Claude Code or any OpenAI-compatible API.
