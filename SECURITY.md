# Reporting a vulnerability

Use this repository's **Security** tab, then **Report a vulnerability**, to send
a private report through GitHub. Keep vulnerability details out of public issues.

Include the affected Oops version, macOS version, steps to reproduce the problem
and its impact. Use made-up text where possible. Remove API keys, sign-in tokens
and private drafts from any examples or logs.

See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
for the reporting form.
